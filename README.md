This repository contains the R Markdown, written for producing the figures in the manuscript 'Connectivity of Fennoscandian Shield terrestrial deep biosphere microbiomes with surface communities': https://doi.org/10.1038/s42003-021-02980-8. The R script requires the ASV table (```seqtab.tsv.gz```), the taxonomy table (```taxonomy.tsv.gz```), the sample metadata (```smd.tsv```), the cell counts (```cellnumbers.tsv```), and the chemistry data (```chemistry.tsv```).
